# Zhushan placeholders

Abstract / editorial preview visuals for https://hoyao.com/zhushan/

Replace these with official photographs when ready:

1. Update `images.*` paths in `assets/js/zhushan-config.js`
2. Set `placeholder: false` (or remove the flag)
3. Optionally set `placeholders.enabled` to `false`

Do not delete this folder until all production images are live.
