  - `/zh/applications/`、`/en/applications/`（列表）

---

## 2. 個案建議欄位

| 欄位 | 說明 | 上架門檻 |
|------|------|----------|
| `slug` / 中英標題 | 穩定識別 | 必填 |
| `site_type` | 應用場域類型（如教育／空間） | 必填 |
| `user_needs` | 使用者需求（可公開） | 建議 |
| `material_form` | 材料特性與形式 | 必填 |
| `process_notes` | 樣品與製作過程（可公開範圍） | 可空 |
| `validation` | 已完成測試與驗證（僅已完成且可公開） | 可空 |
| `integration` | 材料導入方式 | 可空 |
| `outcomes` | 可公開應用成果 | 建議 |
| `collaboration_model` | 商業合作模式（概括） | 可空 |
| `media` | 已授權影像 | 規則控管 |
| `publish` | 僅當實際完成且核准公開 | 閘門 |

---

## 3. 特別限制

1. 不在 SBIR 新聞中預先介紹幼兒園案例  
2. 不在案例中主動設置 SBIR 宣傳導流  
3. 不在 Sitemap／Schema／標籤刻意建立個別補助計畫關聯  
4. 不得因低調而虛假陳述  
5. 若契約要求成果公開或資助標示，依規定履行  
6. 不得將合作單位技術／設備／配方描述為和曜完全自有  
7. 未完成實際驗證前，不得宣稱已認證、量產或正式商用
