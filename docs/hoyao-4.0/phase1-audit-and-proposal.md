## 1. 全站審查摘要

### 1.1 整體判斷

官網目前完成「品牌敘事 + 研發方向 + 少數可公開節點」的展示層，質感與謹慎用字大致合宜（少見過度宣稱）。  
對「正式應用科技公司網站」目標，主要缺口是：

1. **商業定位與服務入口不夠清楚**（客戶不知道能洽什麼）  
2. **技術可信度結構不足**（領域頁過短，未區分能力／階段／合作方式）  
3. **成果履歷偏薄**（育成進駐 + 竹山 + 交流動態；SBIR／獎項等尚未入站且需核實）  
4. **材料／產品資料層尚未建立**（無法承載後續可擴充目錄）  
5. **英文品牌呈現與法定名稱尚未統一規範**

### 1.2 逐頁問題清單（分類）

圖例：

- **Bug**＝確定的程式／標記／一致性錯誤  
- **Verify**＝內容待核實（不可逕行上線宣稱）  
- **Biz**＝商業／內容架構優化建議

### 5.2 Materials／材料頁｜資料架構（不上架不完整項目）

建議欄位（與需求對齊）：

| 欄位 | 說明 | 上架門檻 |
|------|------|----------|
| `id` / `slug` | 穩定識別 | 必填 |
| `name_zh` / `name_en` | 材料名稱 | 必填 |
| `category` | 分類（生物基／防火／先進複合等） | 必填 |
| `source` | 來源（農林副產、竹材、再生料等） | 建議 |
| `form` | 形式及粒徑／型態 | 有則填 |
| `status` | `research` / `sampling` / `validation` / `limited_supply` / `not_public` | 必填 |
| `public_tech_notes` | 可公開技術資料（無數據則不填） | 可空 |
| `applications` | 可能應用（標示為潛在） | 可空 |
| `inquiry` | 詢價或合作方式（mailto／表單意圖） | 必填才能公開頁 |
| `evidence_links` | 內部佐證連結（不上網） | 內部 |
| `publish` | `true` 僅當：名稱＋分類＋status＋inquiry 齊，且**非**把 research 寫成可供貨 | 規則控管 |

**規則：** `status` 為 `research`／`sampling`／`validation` 時，前端僅能顯示「研發／評估中」，**不得**出現「現貨／量產／已認證」措辭。  
資料不完整 → `publish: false`，不進列表。
